# 0.28.0 full-folder selector-generation QA

Isolated release verified 2026-10-16 at 12:24 Eastern; not installed over Main. QA0.27 remains frozen. Data and Library are not migrated or edited. Full goal remains active and incomplete.

This milestone removes the missing-bundle generation gap. Native Rust reads only the installed game's three stock selector resources using the proven exact-size/CRC Oodle decoder policy, retains a content-verified portable cache, and applies the preserved WPF multi-configuration planner. Fifteen synthetic WPF planning cases and all three table payloads are checked against the original implementation; sixty lower-level table-builder cases remain covered. No .NET or Node runtime is added.

Existing complete user selector bundles take priority and are retained unchanged. Incomplete/corrupt bundles block launch rather than being overwritten. Generation occurs only when all three are absent. Unsupported or ambiguous definitions are reported, without approximate donor selection. Existing custom bundles are not automatically regenerated when additional mods are added; their compatibility/coverage remains the user's bundle responsibility pending a separate safe refresh workflow.

Fresh generated tables are published before Steam dispatch for early engine reads, while the provider serves immutable matching bytes. A create-new durable intent precedes nonce staging; file identities are durable before no-replace publication. Exact-session, root-directory, file-identity and SHA checks protect game-closed restoration. User-created/replaced files are never removed. Alternate-profile recovery is anchored by the still-retained profile receipt. Orphaned selector receipts block another launch. Provider transport/read leases and cached handles drain before owned table/link cleanup.

The launch confirmation explains generation and temporary files. Activated status distinguishes existing versus generated bundles and reports skipped sets. The sidebar version caption now follows the actual backend version.
