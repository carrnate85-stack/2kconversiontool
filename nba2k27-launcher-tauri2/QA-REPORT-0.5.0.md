# Rust / Tauri 2 prototype 0.5.0 — QA milestone, 2026-10-11

Offline parity milestone, not a replacement for Main. Live game integration remains disabled.

## Added and corrected

- Player DNA season history now has compact summaries, editable raw totals, normal-team selectors, a second-team field, all eleven season awards, local add/remove and reset.
- Import stats opens player search and a separate season-review popup. Only normal teams are offered; unique source-name matches autofill. Missing mappings must be chosen explicitly.
- Native catalog staging accepts only records belonging to the chosen player and validated normal-team mappings. Selected years replace matching draft years, preserving other years and unrelated player fields. With awards excluded, existing awards survive; new years initialize zero awards, matching WPF.
- Stats now reach the actual Player DNA draft, local save and version-2 `.2kplayer` export. They no longer have to exist only as a disconnected scratchpad draft. The older scratchpad below is retained separately and clearly documented.
- Fixed numeric-year duplicate detection: equivalent JSON years such as 2019 and 2019.0 now share a normalized identity. The new native merge safely handles integral floating-point years without an unwrap panic.
- Search-result generation guards prevent a pending search response from overwriting loading state while a player is being opened. Import review controls are disabled while staging.

## Tests

- 244 native season-merge oracle cases generated by the unchanged WPF `mergeReviewed` function: range/award boundaries, preserved awards, duplicates, ambiguous years, metadata stripping and the 25-row limit.
- Native catalog scope/team review tests reject foreign records, historic team mappings and empty selection; verify destination fields survive and excluded awards are retained.
- Existing 10,517 outfit, 2,444 Player DNA and 2,059 Team DNA oracle cases remain. All 4,274 bundled players are still validated.
- Strict TypeScript/Vite build, 40 Rust tests, 10 frontend tests and 47 packaged GUI checks passed (97 distinct suite checks). Oracle cases are assertions inside the native suite, not additional gameplay tests.
- New GUI coverage exercises search → season popup → team override → staging → returned editor, totals/awards save, invalid-save file preservation, season removal/reset and version-2 sharing.

## Remaining parity and manual checks

Average/percentage editing and scoring-mix recalculation, Basketball Reference URL import, live destination-team mapping and verified game saves are not ported. Current averages are read-only calculations; editable totals must pass native consistency checks on Save. Imported legacy team names remain available rather than being silently rewritten.

Native file-picker interaction and manual visual comparison still need acceptance. Main parity also requires game launch/Steam checks, helper ownership and session restoration/rearming, real F8/live customization, camera tracking, video timing/Xbox/Mixer integration, in-game Jukebox, live roster/team/staff binding, strategy/playbooks, mannequin/animations, diagnostics and update/migration transactions. No full-parity claim is made.

The Rust 1.99.0 compiler/environment fault from prior milestones remains undiagnosed. This optimized build uses one-core affinity on its isolated build shell only, not a persistent system change or reduced release optimization. Acceptance repeats use the app unpinned. Passing tests do not establish a reproducible clean-build fix; see prior QA reports.
