# 2K Conversion Tool

Windows character conversion and modding GUI for ZIP-style NBA 2K IFF packages.

The public repository contains the application source and build configuration only.
Game-derived assets, third-party executables, private-beta bundles, and release
packages are intentionally excluded.

## Local development

Run `Launch Character Mod Tool.bat` to use an existing packaged build or the local
Python environment. Release packages are produced with `build_release.ps1`.

Blender 5.1 is required for background mesh transfers.

Developer handoff notes for the external hair converters are in
`HAIR_CONVERSION_HANDOFF.md`.
