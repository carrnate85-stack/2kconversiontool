Built-in NBA 2K23 player catalog

Bundled with the launcher; no separate download or original game save is required.
Loaded on demand by Player DNA. A user-imported custom catalog takes precedence.

4,274 source player records (current, historic, all-time and unassigned versions).
180 reviewed target fields per player; 8,605 linked season records.
Original calendar years are retained. Unsupported badge, signature, contract,
game-asset and other mappings are explicitly excluded rather than guessed.
This package contains translated player data, not the original save or game assets.
